Since Our Last Meetup (September 10)

  • Claude Opus 5.5 & Sonnet 5.5 — new default Opus and Sonnet, both 1M context; Opus $4/$20 per MTok, Sonnet $2/$10 (Sep 22 & 28)
  • Auto mode is the default — new sessions start in auto mode; the classifier now runs server-side at no extra cost (Sep 19–28)
  • Claude Mods — plugins can now change Claude Code from the inside: panes, status lines, blocking or rewriting tool calls (Oct 1)
  • "You should know" — a built-in mod: a side agent watches your session and flags what you or Claude might miss (Oct 1)
  • AGENTS.md fallback — no CLAUDE.md? Claude Code reads AGENTS.md instead (Sep 18)
  • Send-now & draft recovery — Ctrl+Enter interrupts the turn and sends your queued messages; Up arrow brings back a prompt you cleared with Ctrl+C (Sep 17 & Oct 2)
Rapid fire — six things. One: two new models. Claude Opus 5.5 landed September 22 and is the new default Opus — a million tokens of context at four and twenty dollars per million, which is 40 percent cheaper than Opus 5. Sonnet 5.5 followed September 28 at two and ten. And Pro plans now default to Opus instead of Sonnet. Two: auto mode is now the default permission mode for new interactive sessions, and the classifier that approves or denies runs on the server at no extra charge. Remember the dangerously-skip-permissions hands — this is the grown-up version. Three: Claude Mods, October 1. Plugins used to add tools and skills; mods run inside the Claude Code process and can draw a live pane beside the transcript, add a status line, or block and rewrite tool calls before they run. They hot-reload while you work, and Claude can write them for you. Four: the first built-in mod is called You Should Know — a side agent that watches your session and flags things you or Claude might miss. Enable it with /plugin enable cc-plugin-you-should-know@builtin. Five: AGENTS.md support — if a project has no CLAUDE.md, Claude Code reads AGENTS.md, so the cross-tool standard just works. Six: two small quality-of-life wins — Ctrl+Enter now interrupts the current turn and sends everything you've queued, and if you Ctrl+C a prompt by accident, Up arrow brings the draft back, pasted images and all. Honorable mentions if anyone asks: claude --desktop opens the desktop app on your current directory, /doctor prompt-audit checks your CLAUDE.md and skills for patterns written for older models, the Agent tool takes an effort parameter now, fast mode works in cloud sessions, claude plugin eval gives you scored reproducible plugin evals, and the maxProseWidth setting stops prose from running the full width of a wide terminal. And full disclosure, as always: this slide deck was built by Claude Code.
